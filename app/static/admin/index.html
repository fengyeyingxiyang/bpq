管理功能没有启用：程序没有读到 ADMIN_TOKEN

Docker 部署：
1. 在 docker-compose.yml 所在的文件夹里编辑 .env，加一行 ADMIN_TOKEN=你的令牌（等号两边不要空格，不要加引号，令牌用字母数字）。
2. docker compose restart 不会重新读取 .env，必须执行：docker compose up -d --force-recreate
3. 检查容器里有没有：docker exec fault-assistant printenv ADMIN_TOKEN（应显示你的令牌）。
Linux / Windows 程序：.env 必须放在程序文件旁边，文件名就是 .env（Windows 注意不要变成 .env.txt），改完重启程序。
